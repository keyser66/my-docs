# API 参考

以下接口仅用于文档展示，不提供真实服务。

## 查询文档列表

- 请求方法：GET
- 请求路径：/api/docs
- 功能：返回文档条目列表。

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"}
  ]
}
```

## 查询单篇文档

- 请求方法：GET
- 请求路径：/api/docs/{id}
- 功能：按编号返回单篇文档。

### 返回示例

```json
{
  "id": 1,
  "title": "使用指南",
  "content": "本地预览、提交、推送、查看 Actions。"
}
```
